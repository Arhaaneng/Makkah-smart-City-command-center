# Makkah-smart-City-command-center
A Python and Flask based Smart City Management Dashboard featuring district management, budget analytics, project tracking and reports.


🕋 Makkah Smart City Command Center

An educational Python and Flask-based Smart City Management Dashboard prototype inspired by Makkah, Saudi Arabia.

🚀 Project Overview

Makkah Smart City Command Center is a project designed to demonstrate how city management concepts can be organized through Python modules and a visual web dashboard.

✨ Core Features

- District Management
- District Search System
- Population Analysis
- Infrastructure Management
- Development Tracking
- Budget Management
- Resource Management
- Project Management
- Performance Monitoring
- Alerts and Data Validation
- Main Dashboard
- Reports

🖥️ Dashboard

The project includes a visual HTML dashboard served through a Flask application.

🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

📂 Project Files

- "makkahsmartcitycontrolcenter.py" — Main Python project
- "alldone.html" — Visual dashboard
- "app.py" — Flask application
- "requirements.txt" — Python dependencies

⚙️ How to Run

Install dependencies:

pip install -r requirements.txt

Start the application:

python app.py

Open your browser at:

http://127.0.0.1:5000

📌 Project Note

This is an educational prototype using sample data. It is not an official Makkah government system and is not connected to real city infrastructure.
